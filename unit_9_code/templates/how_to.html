API end route: http://127.0.0.1:5000/Get_weather_data

How to make a query:
First: Copy the route above and paste it to your API website
Next: copy your API key and pass it in the headers as an “x-api-key”
Finally: you can either chose to pass an argument for a specific area or date or you can just send the request to query all data

Example area query: http://127.0.0.1:5000/Get_weather_data/?area=Zord
This will query all data from the area Zord, if you want to query by date simply replace “area” with “date” and “Zord” with you desired date (example: “20260123”)
